Курс в двух частях. **Часть I — Node.js с нуля**: сеть, протокол HTTP и рантайм Node без браузера и без фреймворка. Предполагает пройденный **js-lab** — язык (scope, промисы, event loop, DOM, модули) здесь не повторяется, только то, что языковая лаба сознательно не даёт. **Часть II — Express**: ты строишь свой защищённый, протестированный Express-сервис и понимаешь, что из этого потом автоматизирует NestJS.

**Как устроена лаба.** 19 сессий по ~4 часа, 6 шагов в каждой. У каждого шага один ритм: **слова шага → команда по частям → ожидаемый результат → вопросы «Проверь себя»**. Раз в 2–3 сессии — **🔨 «сломать → починить»**: нарочная типичная ошибка, чтобы научиться читать её сообщение. Блоки «Под капотом» и «Если не получилось» открываются по необходимости.

**Два финальных проекта, оба без подсказок.** Часть I заканчивается «Загрузчиком страниц» — CLI-утилитой на голом Node (HTTP-клиент, разбор и перезапись ссылок в HTML, потоковая запись файлов, тесты на моках). Часть II — сквозным проектом **ShareBox**: от первого `node:http`-сервера (сессия 9) до Express с базой, авторизацией, файлами, share-ссылками, тестами и Docker — и в самом конце расширяется до командного пространства с ролями и общими папками.

**Среда.** Node 24 — прямо на твоём Mac (`brew install node@24` или [nodejs.org](https://nodejs.org/)); PostgreSQL 18 — в Docker Compose начиная с сессии части II про базу, **Docker запускается только с твоего согласия**. Лаба самостоятельная, `starter/` не нужен.

Версии: Node 24 LTS, Express 5, PostgreSQL 18, Prisma 7. Все примеры выполнены в контейнере с этим Node (чтобы вывод совпадал у всех), но проходить лабу можно и без Docker — прямо на Mac с тем же Node 24.
