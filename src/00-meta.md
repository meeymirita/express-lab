Это практический курс по **Node.js** и **Express**: ты не обязана ничего знать о Node, а к последней сессии собираешь свой защищённый, протестированный Express-сервис — и понимаешь, что из этого потом автоматизирует NestJS.

**Как устроена лаба.** 11 сессий по ~4 часа, 6–8 шагов в каждой. У каждого шага один ритм: **слова шага → команда по частям → ожидаемый результат → вопросы «Проверь себя»**. Раз в 2–3 сессии — **🔨 «сломать → починить»**: нарочная типичная ошибка, чтобы научиться читать её сообщение. Блоки «Под капотом» и «Если не получилось» открываются по необходимости.

**Сквозной проект ShareBox** — файлообменник со ссылками: пользователь регистрируется, загружает файлы (до 200 МБ) и отправляет другим короткую ссылку на скачивание. От первого `node:http`-сервера без фреймворка (сессия 1) до Express с базой, авторизацией, файлами, share-ссылками, тестами и Docker (сессия 11).

**Среда.** Node 24 — прямо на твоём Mac (`brew install node@24` или [nodejs.org](https://nodejs.org/)); PostgreSQL 18 — в Docker Compose начиная с сессии 5, **Docker запускается только с твоего согласия**. Лаба самостоятельная, `starter/` не нужен.

Версии: Node 24 LTS, Express 5, PostgreSQL 18, Prisma 7. Все примеры выполнены в контейнере с этим Node (чтобы вывод совпадал у всех), но проходить лабу можно и без Docker — прямо на Mac с тем же Node 24.
